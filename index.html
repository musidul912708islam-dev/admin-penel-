🔒 Atomic Locker

Connects this Admin Panel to your GitHub repository so Save/Add/Edit/Remove actions commit directly to your live index.html.

  • GitHub username saved
  • Repository verified
  • Branch verified
  • API connection ready

Security note: because this Admin Panel is a static page with no server of its own, your token is stored only in this browser's local storage and sent directly from this browser to GitHub's API — it is never sent anywhere else. For real server-side secrecy (token never touching any browser), a small backend service would be needed; that isn't something a static file can do. To limit risk, create a fine-grained token scoped only to this one repository with just "Contents: Read and write" permission, not a token with full account access.
